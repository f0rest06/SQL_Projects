# SQL Projects

Hands-on SQL case studies: each project ships the schema with seed data, the business
questions, and worked solutions.

## Projects

| Project | Source | What it covers |
|---|---|---|
| [Danny's Diner](dannys-diner/) | [8 Week SQL Challenge, Case Study #1](https://8weeksqlchallenge.com/case-study-1/) | Customer spend and visit analysis, menu favourites, membership impact, and loyalty-point rules - JOINs, aggregation, ranking, conditional logic |
